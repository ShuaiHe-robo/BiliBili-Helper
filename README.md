# Bilibili取关助手

一个本地运行的 Chrome Manifest V3 扩展，用于读取自己的 B 站关注列表，并在手动勾选、二次确认后限速批量取消关注。

## 安装

1. 解压发布包（如果拿到的是 ZIP）。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `bilibili-unfollow-assistant` 文件夹。
5. 登录哔哩哔哩并打开任意 `bilibili.com` 页面，再点击浏览器工具栏中的扩展图标。

## 使用

1. 等待扩展载入关注列表。第一页用于确定总量，其余页面最多使用 3 路并发读取，以缩短大量关注账号的加载时间。
2. 使用“关注分类”筛选全部关注、默认分组、特别关注或 B 站账号中的自定义关注分类。分类通过当前登录态的 B 站关系接口逐页读取；v1.10.1 修复了大分组只读取首批 50 人的问题。若接口暂时不可用，仍可使用全部关注列表。
   - v1.11.1 修复从“特别关注”切回已缓存的默认分组或自定义分组时列表不刷新的问题。
3. 使用“关注时间”排序器，可选择倒序（最新关注优先）或正序（最早关注优先）；列表会显示每个账号的关注日期。
4. 列表每页显示 5 个账号。点击“下一页并全选”时，会先翻到下一页，再选中新页面上的所有可选账号；“全选本页”“反选本页”和“清空已选”都集中在下方翻页操作栏。“清空已选”可一次清除所有跨页选择。
   - 点击统计栏中的“已选 N · 管理”，可打开右侧抽屉滚动浏览全部已选用户、搜索昵称或 UID、逐个移除，或一键清空已选。
5. 默认会保护“特别关注”，并强制从已选集合中移除特别关注；如确有需要，可手动关闭保护。
6. 选择平均取关间隔和高斯波动比例，点击“取消关注已选 N 人”。取关严格串行；波动比例可选 5%、10%、15%、20%、30%，默认 10%，表示标准差占平均间隔的比例。实际间隔限制在均值的 50%–150%，且不低于 1 秒。随机波动只能减少固定节奏特征，不能保证不触发风控。
7. 在确认窗口核对后执行。插件只使用“取关ing🍵”遮罩显示任务进度，原页面下方不再重复显示进度条。遮罩会阻止弹窗内部误点；即使误点弹窗外部导致弹窗关闭，任务也会在后台继续。重新打开插件即可恢复进度。
8. 遮罩提供“停止后续操作”和“强制中断”：前者等待当前请求结束，后者会立即尝试通过 `AbortController` 中断当前请求。强制中断无法撤销已发送到服务器或已经完成的操作。请保持任务绑定的 B 站标签页打开，且不要将其导航到其他网站。

## 隐私与安全

- 扩展不读取、保存或上传账号密码与 Cookie。
- 所有请求都在当前 B 站页面的登录上下文中直接发给 B 站接口。
- 没有统计服务、远程脚本或第三方依赖。
- 取消关注是账号状态变更，插件无法一键恢复；建议先用少量账号试运行。
- 这是非官方工具。B 站接口或风控策略变化时，插件可能暂时失效；操作过快也可能触发频率限制。

## 文件说明

- `manifest.json`：扩展声明与最小权限。
- `background.js`：在绑定的 B 站标签页执行白名单接口请求，并维护可跨弹窗关闭继续运行的取关队列。
- `popup.html` / `popup.css` / `popup.js`：筛选、选择、确认和进度界面。

## 卸载

在 `chrome://extensions/` 中找到本扩展并点击“移除”。卸载不会恢复已经取消的关注。
